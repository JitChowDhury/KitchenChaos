🍔 Kitchen Chaos
Kitchen Chaos is a fast-paced cooking game where you deliver different types of burgers to customers within a time limit. Prepare orders quickly and accurately — the clock is always ticking!

🎮 Gameplay
Make and deliver burgers based on customer orders

Complete orders within the time limit

The game gets faster and more chaotic as you progress

Controls are shown in-game for easy play

🛠️ Built With
Unity (Game Engine)

C# (Scripting)
